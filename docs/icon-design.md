# Powered Repair icon

`../icon.png` is the canonical icon for the mod metadata and the CurseForge project avatar. It is a square PNG, below the 2 MB limit, and is copied unchanged into every generated module at `assets/<mod_id>/icon.png`.

The ivory open-ended wrench represents repair; the separate mint lightning bolt represents electrical energy. Both symbols have bold silhouettes against a midnight-navy-to-petrol-teal gradient, with soft central illumination and a subtle vignette. This is a project icon, not a replacement block or item texture.

Created with the built-in image generation tool on 2026-11-08. The generated image was copied into the repository without visual edits. This replaces the earlier anvil and pickaxe concepts following feedback about brand similarity and unclear repair/energy symbolism.
